+2. Watch it run. Run ./lab boot, then inside the guest :
```
dd if=/dev/zero bs=64k count=2000 | cat > /dev/null &
bpftrace -e 'kprobe:anon_pipe_write { @[comm] = count(); } kretprobe:anon_pipe_read { @bytes = hist(retval); }'
trace-cmd record -p function_graph -g anon_pipe_write -- sh -c 'echo hi | cat'; trace-cmd report | less
```

function_graph shows the call tree under each write: page allocation, copying from userspace,
the wakeup.
